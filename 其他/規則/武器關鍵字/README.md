# 武器關鍵字資料庫

Warhammer 40,000 第11版核心武器能力的共用唯讀資料庫。

- [完整索引](./武器關鍵字｜索引.md)
- [核心武器關鍵字條目](./條目/)

目前收錄 **21 個查詢條目**，其中「手槍（Pistol）」是與「近距離（Close-quarters）」相同規則的相容性別名；目前掃描三個陣營的 **115 個單位頁**，並在各條目列出使用交叉索引。

資料庫範圍只包含核心規則武器能力，不把單位關鍵字、陣營能力、分遣隊規則或單位專屬裝備能力混入。規則摘要以第11版核心規則24章為基準，並以使用者提供的繁體中文核心規則 PDF 核對術語；詳見[完整索引](./武器關鍵字｜索引.md)。

> 注意：「突擊（Assault）」是武器能力；「突進（Advance）」是移動類型，兩者不可混用。「連擊（Sustained Hits）」依本版核心規則繁中條目保留為連擊。
