# 戰鎚40k個人資料庫

Warhammer 40,000 第11版陣營規則與軍表資料庫。

## 資料庫結構

| 路徑 | 用途 |
|---|---|
| `帝國軍/` | 帝國軍陣營資料，目前包含機械修會，未來可加入其他帝國軍分支。 |
| `帝國軍/機械修會/` | 機械修會單位、分遣隊、Faction Pack 更新、版本稽核與官方規則來源。 |
| `星際戰士/` | 星際戰士陣營資料，目前包含黑暗天使。 |
| `星際戰士/黑暗天使/` | 黑暗天使單位、分遣隊、Faction Pack 更新、版本稽核與規則來源。 |
| `異形/` | 異形陣營資料，目前包含鈦帝國。 |
| `異形/鈦帝國/` | 鈦帝國單位、分遣隊、Faction Pack 更新、版本稽核與規則來源。 |
| `軍表/` | 各陣營軍表、軍表分析、部署建議與擴充規劃。 |
| `其他/規則/` | 不屬於單一陣營的共用規則資料與查詢索引。 |
| `其他/規則/武器關鍵字/` | 第11版核心武器能力、繁體中文規則摘要、英文原文與單位交叉索引。 |
| `軍表/機械修會/` | 機械修會 500 分、1000 分與 2000 分軍表分析、組軍方案與擴充路線。 |
| `軍表/鈦帝國/` | 鈦帝國 1000 分與 2000 分軍表分析、空育／復仇獵核分遣隊協同與危機戰鬥服戰術。 |
| `軍表/黑暗天使/` | 黑暗天使 990 分軍表分析、內環特遣隊協同與死翼／鸚翼三翼戰術。 |
