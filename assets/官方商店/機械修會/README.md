# 機械修會官方商店圖片資產

本資料夾保存機械修會單位頁所使用的 Games Workshop 官方商店產品主圖。圖片僅作為本私人 Warhammer 40,000 資料庫的單位辨識與規則索引參考；所有圖片著作權與相關權利歸 Games Workshop Limited 所有。

## 圖片來源

來源網站：[Games Workshop｜Adeptus Mechanicus](https://www.warhammer.com/en-WW/shop/warhammer-40000/armies-of-the-imperium/adeptus-mechanicus)。

每個單位頁的「官方產品圖片」區塊均附有對應的官方商品頁連結與圖片擷取日期。圖片以官方商店目前提供的產品主圖保存；沒有獨立商品頁的單位，會在單位頁明確標示使用同陣營套裝商品圖作為辨識參考。

## 資產原則

圖片檔名沿用官方商品 slug 的安全化版本，避免中文檔名與特殊字元造成 Markdown 或 Obsidian 路徑問題。相同模型套件對應的不同規則變體可以共用同一張官方產品主圖；這不代表官方商品頁把每個規則變體分別列為獨立產品。
