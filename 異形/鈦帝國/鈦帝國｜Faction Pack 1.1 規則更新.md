# 鈦帝國｜Faction Pack 1.1 規則更新

> **適用版本：** 自 2026 年 7 月 22 日起可用於對戰模式。以下內容優先於鈦帝國 PDF 中相同規則的初始文字。

## 軍隊規則與分遣隊

| 範圍 | 官方更新 |
|---|---|
| 為了上上善道 | 射擊階段開始選擇觀測單位；被指引單位攻擊標記單位時射擊技巧 +1；若觀測單位擁有標記光，攻擊獲得忽視掩體。 |
| 空育 | 第三至第五戰鬥輪次的遠程武器獲得連擊 1；被指引單位可忽視射擊技巧與命中骰修正。 |
| 蒙特卡 | 第一至第三戰鬥輪次的遠程武器獲得突擊；被指引單位獲得致命一擊。 |
| 考雍／協同觀瞄 | 領導聯合單位作為觀測單位時，依官方版本使被指引單位獲得連擊 1 或致命一擊。 |
| 反擊核心隊 | 清汐記憶神經芯片改為以 4+ 機會取得 1 CP。 |
| 團結英雄分遣隊 | 12 吋內的戰鬥服模型遠程攻擊力量 +1；8 吋內另獲護甲穿透 +1。 |

## 資料表修訂

| 單位或規則 | 修訂內容 |
|---|---|
| 雙矛 | 新型電容護盾依官方版本：12 吋內可見敵方單位須進行戰鬥震懾，該回合衝鋒骰 -1；武器與增強型反向推進器採官方資料表。 |
| 隱形戰鬥服小隊 | 前線觀測改為被指引單位攻擊標記單位時重骰命中與造傷結果 1；定位信標距離由 9 吋改為 8 吋。 |
| 胡蜂尖翼戰士 | 官方資料表取代聖典舊表；靈敏飛行、照管無人機與武器選項依官方版本。 |
| 以太長老 | 補上「為了上上善道」陣營技能。 |
| 火刃隊長 | 精準定位改為對標記單位攻擊時可重骰命中骰。 |
| 克魯特尋跡塑形者 | 克魯特伏擊改為雙方部署後重新部署；搜尋蹤跡觸發距離改為 8 吋。 |
| 尋路者小隊 | 目標已上傳改為對標記單位攻擊時射擊技巧 +1 且獲得忽視掩體。 |
| 危機日鑄戰鬥服小隊 | 陽鑄改為對巨獸或載具目標可重骰造傷與傷害骰。 |
| 激流戰鬥服 | 離子加速器為 72 吋、6A、S9／S10、AP -2／-3、D3／D4；新星充能改為每場戰鬥一次使一件遠程武器獲得毀滅傷害。 |
| 剃刀鯊戰鬥機／陽鯊轟炸機 | 加入外殼關鍵字；M 與 OC 改為「—」；陽鯊脈衝炸彈依官方近戰階段結束時的修訂文字。 |
| 魔鬼魚／錘頭鯊／食人魚／天魟／潮汐工事 | 相關資料表補上外殼關鍵字。 |
