# 黑暗天使｜Faction Pack 1.1 規則更新

> **適用版本：** 自 2026 年 7 月 22 日起可用於對戰模式。以下內容優先於黑暗天使 PDF 1.02 中相同規則的初始文字。

## 分遣隊與通用規則

| 範圍 | 官方更新 |
|---|---|
| 黑暗年代軍備庫 | 帶有「等離子」字樣的武器資料表視為等離子武器資料表，力量屬性 +1。穩定祈禱、永燃祈求、灼熱爆裂、不惜萬死與罪孽啟示依官方版本。 |
| 暗翼追擊隊 | 鸚翼飛行單位的遠程攻擊獲得「忽視掩體」；雷霆罩式、夜鍛炮組與空基監視、陰影之翼、吾即復仇依官方版本。 |
| 審訊密會團 | 牧師消滅敵方單位時觸發附近敵方戰鬥震懾；牧師獲得恐懼播撒者光環；無盡狂熱、無秘可瞞、嚴苛懲處與可怖狂熱依官方版本。 |
| 雄獅之刃特遣隊 | 落入獅爪、卡利班制武器、追獵領主、堅毅勇士、震天迅雷與六項策略採用官方修訂文字。 |
| 巨石之怒 | 堅毅恪守、戰火淬鍊、遠古神兵、死翼突襲、鸚翼之主與官方策略採用 Faction Pack 1.1 版本。 |

## 資料表修訂

| 單位或規則 | 修訂內容 |
|---|---|
| 萊昂・艾爾・莊森 | 加入「機動」；迷霧籠罩的陰影國度可在對手移動階段結束時進入戰略預備隊；戰鬥典範與第一軍團基因原體採用官方文字。 |
| 死翼終結者小隊 | 黑暗守望者提供致命傷不知疼痛 4+；傳送信標部署距離改為敵方模型 8 吋外。 |
| 死翼騎士 | 傳送信標距離改為 8 吋；赦免槌與動力武器資料表更新。 |
| 內環伙友 | 審判烈焰改為本單位獲得隱蔽，且對本單位的近戰攻擊命中結果 -1；卡利班巨劍依官方數值。 |
| 復仇型蘭德速攻艇 | 等離子風暴炮台標準與過載數值更新，並加入外殼關鍵字。 |
| 鸚翼暗幕 | 舊卡利班聖物光環改為 6 吋內友方阿斯塔特修會單位擁有隱蔽。 |
| 鸚翼黑爪轟炸機 | 靜滯炸彈改為對手近戰階段結束時觸發，並依 D6 結果施加致命傷與移動減益。 |
| 涅法雷姆戰機 | 移除懸浮；M 與 OC 改為「—」；閃電機動改為對攻擊的造傷結果 -1。 |
| 鸚翼指揮小隊 | 關鍵字移除領袖並加入支援；榮譽或死亡使突進與衝鋒 +1，並降低英勇介入 CP。 |
| 薩麥爾 | 遠程攻擊獲突擊；突進不阻止衝鋒；加入機動。 |
